## Important notes & recommendations ⚠️
- On Windows (especially Windows on ARM or where wheels aren't available), `numpy`, `pandas`, and `scikit-learn` often require either:
  - pre-built wheels for your platform (use conda/miniforge or find matching wheels), or
  - system-level build tools (Visual Studio build tools) and other toolchain components (meson, ninja).
- If you run the setup.ps1 and pip shows an error about `meson` or `msvc`, consider:
  - Using conda/miniforge to create a Python environment that provides wheels for these libraries:
    - e.g., conda create -n myenv python=3.11 numpy pandas scikit-learn -c conda-forge
  - Installing Microsoft Build Tools for Windows or the required build tools on Linux/macOS to compile the binary wheels.
- I selected SQLAlchemy 1.4.x instead of 2.0 to reduce code migration risk, while still offering modern support.
